# 🎮 XO GAME – Tic-Tac-Toe

## 📌 Présentation

XO Game est un jeu de morpion développé en HTML, CSS et JavaScript Vanilla.

Le joueur incarne X et affronte une machine qui joue avec le symbole O. Le jeu repose sur une grille de 3 × 3 cases et permet de mettre en pratique les fondamentaux du développement Front-End, notamment la manipulation du DOM, la gestion des événements et les conditions logiques en JavaScript.

Ce projet a été réalisé dans le cadre de ma montée en compétences en développement web.

## ✨ Fonctionnalités

- Interface de jeu composée d'une grille de 3 × 3 cases.
- Interaction avec les cases grâce aux événements JavaScript.
- Jeu opposant un joueur humain (X) à une machine (O).
- Sélection automatique d'une case disponible par la machine.
- Gestion des conditions de victoire et de défaite.
- Mise à jour dynamique de l'interface en fonction des actions du joueur.

## 🛠️ Technologies utilisées

| Technologie | Utilisation |
|---|---|
| HTML5 | Structure de l'application |
| CSS3 | Mise en forme et grille de jeu |
| JavaScript Vanilla | Logique du jeu et interactions avec le DOM |

## 🧠 Compétences techniques mobilisées

**JavaScript :**
- Manipulation du DOM.
- Gestion des événements utilisateur.
- Utilisation de `Math.random()` pour la sélection d'une case par la machine.
- Utilisation de `filter()` pour identifier les cases disponibles.
- Gestion des conditions et de la logique du jeu.
- Mise à jour dynamique des éléments HTML.

**CSS :**
- Utilisation de CSS Grid pour construire une grille de jeu en 3 × 3.
- Gestion de la mise en page et des interactions visuelles.

## 🚀 Installation et lancement

Aucune installation de dépendance n'est nécessaire.

1. Cloner le dépôt GitHub :

   ```bash
   git clone https://github.com/DavidMB050/XOGAME.git
   ```

2. Accéder au dossier du projet :

   ```bash
   cd XOGAME
   ```

3. Ouvrir le fichier HTML principal dans un navigateur web.

## 📁 Structure du projet

L'application repose sur trois technologies principales :

- HTML : structure de la page.
- CSS : présentation graphique et grille de jeu.
- JavaScript : gestion des interactions et logique du jeu.
